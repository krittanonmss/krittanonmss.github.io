# Krittanon Museesut — Portfolio

Personal portfolio built with HTML, Tailwind CSS and JavaScript, hosted on GitHub Pages.

- Original responsive layout, project carousel, theme toggle and Thai / English support
- Skills and technologies with logos, expanded from the Thai resume
- Projects in `projects.json`, ordered by business impact and technical depth; MILDSTONE is included from the resume without a public source link
- Open the Thai resume from the hero section: `resume/krittanon_resume_TH.pdf`

Run `python3 -m http.server 8000` and open `http://localhost:8000` for a local preview.
